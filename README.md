# fhl-brain

The Brain: one source of truth for Frosty's Holiday Lighting. Source of truth for the code; the platform runs a synced copy in `src/lib/brain-core/`.

- `npm test` — run the tests (Node 22+, no dependencies).
- `npm run sync -- /path/to/frosty-saas` — copy `src/` into the platform, stamped with this commit.

See `CLAUDE.md` for the rules.
